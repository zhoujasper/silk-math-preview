# OCR 精度与复核

公式 OCR 会整理图片背景和留白，并检查生成结果的结构。复杂表格、模糊图片和手写公式仍需人工核对。

## 识别流程

1. **输入**：先在原分辨率检测背景和笔画，再裁掉外侧空白。保留公式全部区域，包括远离主式的条件和独立标点；不按连通域面积删除笔画。浅色/深色统一白底，保留抗锯齿，低对比度才拉伸灰度。缩放保持比例。
2. **推理**：正常输入只解码一次。低置信度、非法结构、可疑空数组或格线/列数不符才改变边距再试一次，最多两次，不增加模型或并发会话。token 几何平均概率用于同图候选选择，不代表准确率。
3. **结构**：检查花括号、环境配对和表格规则作用域；要求正常 EOS。真实表格可见左右边框和贯穿高度的竖线时，用格线核对列数。不重建无法确定的单元格。
4. **整理**：仅当图像确认为单行、外层为简单无框 `array`、只有一行有效内容且至少两行为空时，允许提取有效内容。优先用再次识别的完整候选，不能凭空补写模型漏掉的条件。无法解决的结果标记复核。`matrix`、`cases`、`aligned`、复杂列声明、外层括号和真实表格不折叠。
5. **输出**：删除数学 token 多余空白，保留 `\alpha x` 的控制词边界、`\ ` 等显式空格和 `\text{...}` 中的文字。智能模式中需要复核的真实表格仍保留整表，不拆成文字行。

## 边界

- 继续使用 `2026-08-18.1` 模型包。图像仅在本机 Worker 内处理，不上传；本次没有训练或替换模型。
- 结构校验不是完整 TeX 语法检查，也不能检测所有语义错误。没有边框的真实表格和多行公式在视觉上可能相似；无法确认时保留结构。
- 复杂表格、合并单元格、模糊/手写公式、字体粗细和超长公式仍需核对。新流程减少已验证的留白/背景问题，不承诺所有图片准确。
- 保留现有 20 MB / 16 MP 输入限制、取消/超时销毁和默认 60 秒空闲释放。识别模块不进入普通公式预览热路径。
